 ## 1. 개발 의도
 
 K-POP 아이돌 그룹을 직접 만들어 보고 싶어서 이 앱을 만들었습니다. 멤버를 고르고 포지션을 정한 뒤 점수를 계산하면 실제로 기획사가 된 것 같은 느낌을 받을 수 있도록 만들었습니다.

또한 단순히 멤버 수가 많은 팀이 유리하지 않도록 멤버별 평균 점수로 계산하는 방법을 사용했습니다.

 

## 2. 적용 대상
 
 - 사용 대상: 여자아이돌에 관심있고 K-POP과 아이돌 게임을 좋아하는 학생

- 사용 상황: 나만의 아이돌 그룹을 만들어 보고 싶을 때
 
 ## 3. 주요 기능과 사용 방법
 
 | 기능 | 설명 |
 | --- | --- |
 | 팀명 입력 | 팀명을 입력합니다. |
 | 멤버 선택 | 2명부터 5명까지 원하는 인원수를 정하고 연습생을 선택합니다.|
 | 포지션 배정 | 멤버의 노래, 춤, 비주얼 능력에 맞게 리더, 메인 보컬, 메인 댄서, 비주얼, 올라운더를 정합니다.|
 | 데뷔곡 선정 및 프로듀싱 방침 | 그룹의 색깔에 맞는 곡과 프로듀싱 방침을 결정합니다.|
 | 점수와 등급 계산 | 멤버별 평균 점수와 포지션 적합도를 계산하고 S, A, B, C, D, F 등급을 보여 줍니다.|
 | 럭키박스 | 결과를 보기 전에 점수 보너스를 받을 수 있습니다. |
 | 기획사 룰렛 | 5개 기획사 중 룰렛 화살표가 가리키는 기획사가 정해집니다. 멤버의 능력과 기획사 특징이 잘 맞으면 추가 점수를 얻습니다. |
 | 데뷔심사| 심사 시작 버튼을 누르면 프로그레스바가 진행되고 심사 결과가 표시됩니다.|
 | 명예의 전당 | 랭킹 등록을 하면 TOP5 팀으로 저장됩니다. 팀을 누르면 점수, 기획사, 멤버 사진을 볼 수 있습니다. |
  



**사용 방법**
 
 1. 앱 주소에 접속합니다.
 2. 팀 이름과 데뷔할 멤버 수를 정합니다.
 3. 연습생을 골라 포지션을 배정합니다.
 4. 그룹의 색깔에 맞는 곡과 프로듀싱 방침을 결정합니다.
 5. 럭키박스 2개를 고르고 기획사 룰렛을 돌립니다.
 6. 심사 시작 버튼을 눌러 결과와 등급을 확인합니다.
 7. 원하는 경우 랭킹에 등록하고 결과 이미지를 다운로드합니다.
  

※ 메인 화면에서 팀명 한칸띄고 삭제라고 입력하면 명예의 전당에 있는 해당 팀을 삭제할 수 있습니다.



## 4. 기대 효과
 이 앱을 사용하면 아이돌 그룹을 만드는 과정을 재미있게 체험할 수 있습니다. 멤버의 장점과 부족한 점을 비교하면서 포지션을 정하는 연습도 할 수 있습니다.또한 점수가 평균으로 계산되기 때문에 팀 인원수가 달라도 공정하게 비교할 수 있습니다.

 ## 6. 사용한 AI와 제작 과정
 
 - **사용한 AI 도구**: ChatGPT
 
 - **처음에 AI에게 한 요청(프롬프트)**:
 
   > K-POP 걸그룹을 직접 만들 수 있는 HTML 게임을 만들어 줘. 팀 이름과 멤버 수를 정하고 연습생을 선택한 뒤 선택 완료 버튼을 누르면 다음 단계로 넘어가게 해 줘.
 
 - **AI가 만든 결과에서 내가 고치거나 추가한 부분**:
 
 1) 멤버 선택, 포지션 배정, 럭키박스, 기획사 룰렛을 단계별로 구성했습니다.

 2) 인원수가 많은 팀만 유리해지지 않도록 멤버별 평균 점수로 계산하도록 했습니다.

 3) 심사 진행바, 등급 표시, 명예의 전당, 결과 이미지 다운로드 기능을 추가했습니다.

 4) 멤버 사진을 html 파일 하나로 처리하려니 index.html파일이 너무커져 AI가처리를 못해서 img 폴더에서 불러오도록 연결하고 명예의 전당 상세 화면에도 사진이 나오게 했습니다.





- **어려웠던 점과 해결한 방법**:
 
 1)처음에는 index.html 하나의 파일에 모두 들어 있어서 내용이 길어서 AI가 답변을 잘 못해주는 경우가 있었습니다. AI가 해결방법으로 파일을 나누는 것을 제안해줘서 파일을 기능별로 나누어 작업을 했습니다.

 2) 모바일에서 화면이 깨지는 문제가 있었는데 AI가 반응형 디자인을 적용하면 될 것 같다고해서 반응혀을 적용하여 해결했습니다.

 3) 다시하기를 눌러도 럭키박스 효과가 남아 있는 오류가 있어 AI에게 문제점을 알려주고 수정했습니다.

 4) 모바일에서는 버튼이 너무 작아서 누르기 어려웠는데 버튼 크기와 간격을 조정하여 해결했습니다.

 8) 테스트한 결과를 제거가 필요해서 동일 팀이름 입력 한칸띄우고 삭제 라고 입력하면 지워지도록 수정했습니다.

 9) 처음에는 실제 여자아이돌 사진과 이름을 사용하려고 했는데 AI가 저작권등 문제 가능성을 알려줘서 가명과 가상 아이돌 이미지를 생성하였습니다.
